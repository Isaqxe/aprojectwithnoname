# GPT Workspace

Área experimental reservada para modificações, testes e protótipos desenvolvidos com auxílio do GPT.

Regra:
- Alterações feitas aqui não representam automaticamente a versão oficial do projeto.
- Após testes e validação, mudanças podem ser migradas para a estrutura principal.

Objetivo:
Manter um ambiente controlado para experimentação sem comprometer a versão estável do Alive Cells.
